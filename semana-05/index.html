Semana 5 · Checkpoint 1: repositorio y Pull Request

Tu PIA vive en un repositorio de GitHub: cada avance llega por una rama y un Pull Request que el docente revisa antes de fusionarlo. Practica ese flujo, organiza el repositorio y elige con criterio el dataset del equipo.

Objetivo

Al terminar podrás ejecutar el flujo de rama, commit, Pull Request, revisión y fusión del checkpoint-1; organizar el repositorio del PIA con el proyecto guardado como PBIP, y justificar la elección del dataset con los criterios de la guía.

Cómo usarlo

  1. En el Reto 1 elige la acción correcta en cada paso: el grafo de commits, la terminal y el Pull Request se actualizan.
  2. En el Reto 2 selecciona un archivo y luego su carpeta destino (con clic o con Enter).
  3. En el Reto 3 evalúa los cuatro datasets y arma la justificación del README.

# una sola vez
git clone https://github.com/<usuario>/pia-dashboard-amenazas.git   # <usuario>: quien creó el repositorio
cd pia-dashboard-amenazas
git switch -c checkpoint-1          # equivale a: git checkout -b checkpoint-1
# cada avance
git add README.md reportes dashboard capturas .gitignore
git commit -m "Agrega README con integrantes, dataset y justificación"
git push -u origin checkpoint-1
# después de fusionar el Pull Request en GitHub
git switch main
git pull

      
En GitHub: Compare & pull request con base main ← compare checkpoint-1; el docente revisa en Files changed; ustedes corrigen con nuevos commits en la misma rama; al final Merge pull request › Confirm merge y Delete branch. Git no guarda carpetas vacías: pon al menos un archivo en cada una.

    


    

      
Para tu PIA

      
Esta semana es el checkpoint-1 (EV01, en equipo de 2): repositorio compartido con README.md, reportes/, dashboard/, capturas/ y .gitignore; el docente como colaborador; rama checkpoint-1 y un Pull Request hacia main con (a) el dataset identificado y accesible, (b) la justificación de su relevancia y (c) el primer boceto de las tablas que van a relacionar. Atiendan la revisión con nuevos commits y fusionen. El mismo flujo se repite en la Semana 10 (checkpoint-2) y en la Semana 15 (entrega-final).
