Semana 12 · Jerarquía visual en el dashboard

Tu audiencia decide en segundos qué mirar. Si la conclusión está escondida entre gráficas decorativas, nadie la verá. Hoy rediseñas una vista saturada, eliges el gráfico adecuado para cada pregunta e interpretas resultados sin exagerar.

Objetivo

Al terminar podrás organizar una vista de dashboard con jerarquía visual (lectura en Z/F, tamaño según importancia, color de alerta reservado y títulos con conclusión), elegir el tipo de gráfico según la pregunta e identificar qué conclusiones permite y cuáles no permite una gráfica.

Cómo usarlo

  1. Reto 1: elige un visual de la paleta (o del lienzo), su tamaño y luego la casilla donde va. Todo funciona con Tab y Enter.
  2. Observa cómo se redibuja la vista previa y cómo cambia el puntaje de cada regla.
  3. Retos 2 y 3: elige respuestas, usa los botones de cada gráfica y lee la explicación.

    Reto 2 · El gráfico correcto para cada pregunta

    Cada pregunta pide un tipo de análisis: tendencia, comparación, composición, distribución, relación o valor único. Elige un gráfico y mira cómo se ven esos mismos datos con él: la vista previa te ayuda a descubrir por qué algunas opciones no funcionan.

    Reto 3 · ¿Qué puedes afirmar con esta gráfica?

    Interpretar también es saber qué no puedes concluir. Para cada gráfica, usa el botón para ver más contexto y elige la única afirmación que los datos sí sostienen.

    Así se hace en Power BI

    1. Rejilla: en Power BI Desktop, pestaña Vista, activa Líneas de cuadrícula y Ajustar a la cuadrícula. Para tamaños exactos: panel Formato del objeto visual → General → Propiedades → Tamaño y Posición.
    2. Orden de lectura: Vista → Selección. En la pestaña Orden de tabulación deja primero los KPI y al final la tabla: así también navega quien usa teclado o lector de pantalla.
    3. Segmentadores: el visual se llama Segmentación de datos. Agrúpalos (selecciónalos, clic derecho → Agrupar) en un borde de la página.
    4. Color reservado: Vista → Temas → Personalizar el tema actual para fijar un color base; el rojo aplícalo solo con formato condicional (en el panel Formato, botón fx junto al color).
    5. Título con conclusión: crea una medida de texto y úsala en Formato → General → Título → fx (Valor del campo):
    Título tendencia =
VAR Actual = [Alertas críticas]
VAR Anterior = CALCULATE( [Alertas críticas], DATEADD( Calendario[Fecha], -7, DAY ) )
VAR Cambio = DIVIDE( Actual - Anterior, Anterior )
RETURN
    "Las alertas críticas " & IF( Cambio >= 0, "subieron ", "bajaron " )
        & FORMAT( ABS( Cambio ), "0%" ) & " frente a la semana anterior"

    Power BI no tiene un visual de histograma nativo: clic derecho en la columna numérica → Nuevo grupo → tipo Discretización, y usa los intervalos en un gráfico de columnas.
